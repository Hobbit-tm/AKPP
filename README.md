# АКПП-Сервис

Полный Vite + React + Tailwind проект с рабочими CTA-кнопками и GitHub Pages deploy.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## GitHub Pages

В репозитории включи:
**Settings → Pages → Source → GitHub Actions**

Workflow настроен под ветку `main`.
